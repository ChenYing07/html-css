# Responsive card gallery: my answers

## 1. Which element became the flex container?
card-gallery became the flex container

## 2. Which elements became the flex items?
gallery-card became the flex items.

## 3. Which CSS property controlled the space between the cards?
gap controlled the space between the cards.

## 4. Which CSS property let the cards move onto a new row?
flex-wrap: wrap; makes the cards move onto a new row

## 5. What happened when you changed the starting width of the cards?
The cards became thinner when i changed its width to 220px, but when i changed to a number higher than the max-width it doenst change anything.
